# High Code AI Agents Suite

A centralized repository of enterprise-grade autonomous AI agents built on **Google Agent Development Kit (ADK)**, **Gemini 2.5**, and **Google Cloud Vertex AI Agent Engine / Reasoning Engine**.

---

## 📂 Active Agent Packages

### 1. 🍪 [ITC Brand Marketing AI Agent](./itc_brand_marketing_agent)
- **Framework**: Google Agent Development Kit (ADK) & Vertex AI Reasoning Engine
- **Generative Media**: Google Veo (1080p MP4 Commercials), Gemini 2.5 Flash Image & Imagen 3
- **Capabilities**:
  - Native in-image 3D commercial typography and brand taglines
  - 100% IAB LEAN banner generation and lossless aspect ratio adapters (LANCZOS)
  - Autonomous 4-part creative hook synthesis and campaign brief ingestion
  - Multi-channel media budget allocations (YouTube, Meta, GDN, Quick-Commerce) with automated CSV generation
  - In-chat session artifact downloads & Cloud Storage synchronization

---

## 🚀 Quickstart

Each agent in this repository is completely self-contained in its respective directory.

```bash
cd itc_brand_marketing_agent
pip install -r requirements.txt
python main.py
```
